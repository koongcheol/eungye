# 축제 부스 적성 테스트 설정 가이드

파일 구성은 이렇습니다.

```
index.html       ← 사이트 본체 (고칠 필요 없음)
config.js        ← 학교 이름, 구글폼 링크, 질문, 선배 작품 목록 (여기만 수정)
apps-script.gs   ← 실시간 통계용 스크립트 (구글 시트에 붙여넣기)
works/           ← 선배 작품 썸네일 사진 넣는 폴더
```

## 1단계. 구글폼 만들기

새 구글폼을 만들고 질문 5개를 **모두 "단답형"**으로 추가합니다. 질문 제목은 아래처럼 해주세요. (통계 스크립트가 제목에 들어간 단어로 칸을 찾아요.)

| 질문 제목 | 들어가는 값 예시 |
|---|---|
| 학년 | 중2 |
| 추천 결과 | 영상제작 / AI / 웹 프로그래밍 |
| 상담 희망 | 예 / 아니오 |
| 점수 | 영상제작 3 / AI 2 / 웹 프로그래밍 3 |
| 이름 | (이름을 받을 때만 추가) |

"필수" 설정은 꺼두세요. 그다음 **응답 탭 → 스프레드시트에 연결**을 눌러 응답 시트를 만듭니다.

## 2단계. 미리 채워진 링크 → config.js

1. 구글폼 편집 화면 오른쪽 위 **⋮ → 미리 채워진 링크 받기**
2. 각 질문에 아래 글자를 그대로 입력 (영어 대문자)
   - 학년 → `GRADE`
   - 추천 결과 → `RESULT`
   - 상담 희망 → `CONSULT`
   - 점수 → `SCORES`
   - 이름 → `NAME`
3. **링크 받기 → 링크 복사**
4. `config.js`의 `FORM_PREFILL_LINK: ""` 따옴표 안에 붙여넣기

이게 끝이에요. 사이트가 링크를 읽어서 어느 질문에 뭘 넣을지 알아서 찾습니다.

## 3단계. 실시간 통계 연결

1. 1단계에서 만든 **응답 스프레드시트**를 엽니다
2. **확장 프로그램 → Apps Script**
3. 기존 코드를 지우고 `apps-script.gs` 내용을 붙여넣고 저장
4. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
5. 권한 승인 (‘고급 → 안전하지 않음으로 이동’이 나와도 본인 스크립트라 괜찮아요)
6. 나온 **웹 앱 URL**을 `config.js`의 `STATS_URL` 에 붙여넣기

이 스크립트는 숫자만 내보내기 때문에, 응답 시트 자체는 공개하지 않아도 됩니다.

## 4단계. 선배 작품 사진 넣기

`works` 폴더에 아래 이름 그대로 사진 8장을 넣으세요.

```
works/
├── video1.jpg   video2.jpg   video3.jpg   video4.jpg   ← 영상 작품 썸네일
└── web1.jpg     web2.jpg     web3.jpg     web4.jpg     ← 웹 작품 썸네일
```

가로 16:9 비율이 가장 예쁘게 나와요. 사진이 .png라면 `config.js`의 `image` 값도 `.png`로 바꿔주세요.
그다음 `config.js`의 `WORKS` 에서 제목(`title`)과 만든 사람(`author`)만 바꾸면 끝입니다.
`link` 에 유튜브나 사이트 주소를 넣으면 작품을 눌렀을 때 열려요.

## 5단계. 깃허브 페이지에 올리기

1. 깃허브에서 새 저장소(Public)를 만들고 이 폴더의 파일을 전부 업로드
2. **Settings → Pages → Branch: main / (root) → Save**
3. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 주소가 생깁니다

## 축제 당일 사용법

- **학생 폰**: 깃허브 주소로 QR코드를 만들어 인쇄해 붙여두면, 찍어서 바로 시작
- **부스 대형 화면/노트북**: `주소/#stats` 를 열어두면 15초마다 통계가 갱신돼요
- **부스 태블릿**: `주소/?kiosk=60` 으로 열면 60초 동안 아무도 안 만지면 첫 화면으로 돌아가요

## 하루 전에 꼭 해볼 것

1. 폰으로 테스트를 끝까지 한 번 해보고, 구글폼 응답 시트에 줄이 생기는지 확인
2. `#stats` 화면 숫자가 올라가는지 확인
3. 확인이 끝나면 응답 시트에서 테스트 줄을 지우기

와이파이가 끊겨도 응답은 그 기기에 잠시 저장됐다가 다시 연결되면 자동으로 보내집니다.
